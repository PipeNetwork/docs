# Historical Publication

The [2025 PIPE Token Whitepaper](pipe-token-whitepaper-2025.pdf) is retained as a dated publication. It records a notification date of September 3, 2025; it is not the current mainnet storage operating guide.

Pages 11 and 48 describe token-to-Data-Credit conversion, participation incentives, and token-holder decision making. The current storage service uses customer USDC credits and has no individual node rewards. Read [current Tokenomics](../Tokenomics.md) and the [mainnet storage guide](../storage/overview.md) for the operating model documented here.

The PDF is preserved unchanged. A revised whitepaper has not been provided for this documentation update.
